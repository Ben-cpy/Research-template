# 项目目标与边界

初始化时根据用户明确输入填写，未知项保留“未指定”。本页是研究设定，不是已实现能力或实测事实。
后续仅按用户明确指示修订相应边界；不要通过改目标迎合实验结果。
不在本页、AGENTS 或 README 维护当前进度；Agent 按 [workflow](../docs/workflow.md)
自行核验代码、探究记录和运行产物。具体指示按需在相关研究记录保留来源；
任务统一在顶层 `task-doing.md`、`task-done.md` 流转，不另建重复进度表。

| 项目 | 用户输入 |
| --- | --- |
| 宏观目标 | 未指定：希望理解或改善什么，为什么值得研究 |
| 目标场景与对象 | 未指定；例子只作说明，不自动收窄整个研究范围 |
| 硬约束 | 未指定：不可更改的模型/接口/条件及禁止事项；未指定不等于无限制授权 |
| 允许调整的范围 | 未指定：哪些设计或实现可自主改变 |
| 已知环境与资产 | 未指定：设备、模型、数据、访问方式；区分用户自述与当前核验 |
| 资源边界 | 未指定：可用设备、费用、数据权限等；用户明确的总时间或资源上限需遵守 |
| 执行时间偏好 | 单次执行以约 10 分钟为参考，按 workflow 自主安排；不是硬截止或审批周期 |
| 成功价值与 tradeoff | 未指定：希望改善谁的什么体验，哪些损失可接受；不自行发明数值门槛 |
| 非目标 | 未指定：明确本阶段不研究什么 |

## 尚待明确

只记录会影响方向或执行的未知项及其影响；不为填满模板要求用户完成全部采访。
具体方法、评测数据或投稿会议可以保持开放，之后在范围内按问题需要选择。

## 用户明确修订

按需追加日期、指示来源与修订内容；初始化空白不表示用户已经确认任何示例条件。
