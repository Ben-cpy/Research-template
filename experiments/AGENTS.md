# 正式实验约定

继承根 AGENTS、workflow 和交付约定。本目录只放用户选定或已授权论文计划明确包含的
正式实验；001_example 仅教学，不算论文证据。其他探究留在 AI-discover。

- 本文件及各级 README 是稳定说明，日常实验不追加进度、结果或下一步。
- 运行前在 paper/exp_design.md 登记固定编号、来源探究、目的、协议与设计，未完成结果写 TBD。
- 实验 README 只说明稳定用途、配置入口和运行方法；执行细节和实际条件以配置、脚本及运行记录为准。
- 完整配置、源码/输入/环境身份与原始结果按根 workflow 保存；教学示例使用 results 和 provenance 格式。
- 验收后更新 exp_design 的简短结果与结论；paper/plan 只引用编号，不复制结果数值。
- 实际进度自行核验，不把一次跑通等同用户认可，不覆盖探究证据，不让正式代码依赖探究实现。
