# 探究目录说明

本文件是稳定说明，日常探索不修改，也不作为当前进度或候选清单。

```text
<编号_主题>/
  research.md     问题设计、证据判断、竞争解释、用户意见及后续检查理由
  scripts/        按需保存最小实现或调用入口
  配置文件       路径、参数和开关
  runs/<run-id>/  冻结配置、源码身份、原始日志、检查点与结果
```

新问题按递增编号建立目录，不重排已有编号；000_example 只教结构。
可参照 [研究记录模板](000_example/research.md)，不要求每项探究都新增 README。

Agent 接手时自行浏览实际目录、研究记录、业务代码及运行产物，按 [workflow](../docs/workflow.md)
核验做到了哪里，而不是读取一个预先维护的全局进度表。旧记录和下一步建议只是线索，
不能替代当前证据或用户最新指示。

用户可直接查看相关目录中的 research.md，审阅有价值的问题、方法、代价、反证与未知；
也可随时要求 Agent 根据证据汇报。审阅意见按需保留在所属研究记录，不写回 README。

研究记录、配置与脚本进 Git。原始运行产物默认忽略，须单独保存并在所属记录注明备份位置。
