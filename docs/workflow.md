# 如何使用这套科研流程

先复制模板建立自己的 Git 仓库，按根目录 README 完成初始化。
在 `AGENTS.md` 填写项目环境和约束，然后让 Agent 按以下顺序协作。

1. **发现问题**：在网页端讨论相关工作和 idea，将要验证的问题交给 Agent。
   Agent 在 `discover/001_问题名/` 开始最小实验，记录观察、结论和下一步。
   后续探究按编号递增。这里不受 Git 追踪，适合临时尝试。
2. **编码验证**：解决思路确定后，将核心实现整理进 `src/`。
   临时验证仍放在 `discover/`，避免把试验代码混入核心实现。
3. **正式实验**：复制 `experiments/001_example/` 建立自己的实验。
   每个目录回答一个问题，保存配置、启动脚本、结果和图。
   在 `paper/exp_design.md` 逐项追加实验设计，运行后更新结果与结论。
   先做小规模检查，再跑完整实验；同一配置可以中断续跑。
4. **论文写作**：有基本证据后，将会议模板放入 `paper/tex/`。
   填写 `paper/plan.md`，统一主张、术语和章节安排，并引用实验编号；正文写在 TeX 中。

每次停止工作前，更新当前探究或实验 README 的结论和下一步。
值得保留的探究必须整理到正式目录再提交；忽略目录不会被 Git 备份。
失效内容移入 `archive/`，禁止直接删除。
